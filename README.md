# Landing Page - 3D Guincho

Landing page focada em conversão, desenvolvida para campanhas de trágéfo pago (Google Ads), com forte apelo visual e CTA (Call to Action) direto para o WhatsApp.

## 🚀 Tecnologias
* **React**
* **CSS Modules** (para estilização modularizada e sem conflitos)
* **JavaScript (ES6+)**

## 🎯 Objetivo do Projeto
Captar leads qualificados de forma rápida, permitindo que o usuário clique no botão e seja direcionado instantaneamente para o atendimento via WhatsApp da empresa através dos anúncios.
